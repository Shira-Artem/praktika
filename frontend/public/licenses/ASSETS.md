# Assets and licenses

## Kenney Space Kit

The lunar map and rover presentation use PNG assets from **Kenney Space Kit 1.0**.
The pack is released under **CC0 1.0 Universal**. Attribution is not required, but
Kenney is credited here as the original creator.

- Original source pack and license: `frontend/public/licenses/`
- License text: `frontend/public/licenses/License.txt`
- Original inventory inspected for V2: 336 PNG files in `Isometric`, 76 PNG files
  in `Topdown`
- Curated runtime copy: `frontend/public/assets/game/kenney/`

The runtime copy contains 46 source PNGs: 8 terrain props, 14 base/station props,
and 24 directional rover frames (three rover models in eight directions). Files are
copied without changing their names so the relationship to the original pack stays
auditable.

Route curves, beacons, fog, telemetry overlays, particles, selection states, and UI
texture are generated by this project with Phaser Graphics and CSS. Runtime package
licenses are recorded in `package-lock.json`.

## Lunar map background

`frontend/public/assets/game/lunar-map-bg-4x3-2048.webp` and
`frontend/public/assets/game/lunar-map-bg-square-2048.webp` are optimized runtime
copies of the project-provided lunar backgrounds. Phaser selects the version closest
to the central viewport proportions and renders it as the lowest map layer with
proportional cover scaling and centered cropping. Stations, rovers, routes, dust,
terrain props, markers, hit areas, and telemetry remain independent interactive layers
above it.
