🌕 Lunar Dispatch — аналитика

Обновлено: —
Это витрина аналитики игры Lunar Dispatch. Данные берутся из базы ClickHouse через сервис Analytics API. Каждая строка здесь — доказательство, что событие прошло весь путь: игра → Event API → Redpanda → Event Processor → ClickHouse. Играйте на localhost:8080 — цифры внизу обновятся сами (при включённом автообновлении).

Детали

Эффективность роверов

Доля успешных доставок на каждом ровере (delivery_completed против delivery_failed). Показывает, какая машина реально приносит очки, а не только тянет самый тяжёлый груз.

Популярность маршрутов

Сколько раз каждый маршрут (безопасный/быстрый/экономичный до конкретной точки) был реально запущен — по событию delivery_started.

Причины отказа в запуске

Почему игра не дала стартовать доставке — по коду причины из delivery_rejected: перегруз (capacity_exceeded), нехватка заряда (insufficient_battery), занятый ровер и т.д.

Воронка: выбор заказа → запуск → успех

Сколько уникальных игровых сессий дошло от выбора заказа (order_selected) через запуск доставки (delivery_started) до успешного завершения (delivery_completed). Процент — доля, дошедшая до следующего шага.

Типы событий

Из чего состоит поток телеметрии игры. Чем длиннее полоса — тем чаще игроки совершают это действие.

Последние события

Свежие события, только что записанные в базу. Колонка «Свойства» — это поле properties: у каждого типа события свои детали (уровень, сердца, монеты, товар и т.д.).
